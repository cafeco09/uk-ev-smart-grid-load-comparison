# Sources and limitations

## Public data used

The real-data foundation came from UK DfT/DVLA vehicle licensing data, using BEV make/model fleet mix.

The model uses a controlled like-for-like sample, not the raw national fleet totals.

## Key limitation

The UK does not publicly release brand-level private charging telemetry.

That means we cannot directly observe:

- when Tesla owners plug in
- when non-Tesla owners plug in
- home versus public charging by brand
- smart-tariff use by brand
- substation-level brand clustering

## Why this model is still useful

Because owner behaviour is missing, the cleanest fair comparison is:

> same fleet size + same mileage + same charging behaviour + different vehicle-mix efficiency

That tells us whether one vehicle mix is inherently more or less energy intensive under identical grid conditions.
